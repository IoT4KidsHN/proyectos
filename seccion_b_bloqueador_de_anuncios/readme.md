# Bloqueador de anuncios

## ¿Qué es un bloqueador de anuncios?

Bloqueador de anuncios es una herramienta de software
que bloquea la visualización de anuncios en página web.

### Como funciona

Bloquea las comunicaciones con los servidores de anuncios y oculta los elementos de la página
diseñados para mostrar anuncios.

## Tipos

Existen bloqueadores de anuncios en forma de extensiones de navegador, aplicaciones de
escritorio,
Y en algunos casos, en dispositivo de red

## Beneficios de usar un bloqueador de anuncios

- Mayor velocidad de navegación.
- Bloqueador de anuncios a nivel de red.
- Mejora el rendimiento de la red.
- Protege la privacidad.

## Requisitos

Necesitamos un hardware donde hacer correr nuestro servidor DNS, y en este caso usaremos un Raspberry Pi, aunque podemos usar cualquier equipo, Dado que Pi-Hole es un servicio muy liviano, cualquier modelo de RPI es válido (no necesitamos mucha potencia).

Además el sistema bloqueador de publicidad. Pi-Hole al ser, un servidor DNS, puede bloquear también en páginas web que no quieres que se vean dentro de tu red y todo eso sin necesidad de configurar cada dispositivo individualmente, como los móviles que tengas en casa.

## Problema

Anuncios en sitios web; es muy molesto ver que muchos sitios web muestran cada vez más
anuncios intrusivos. Además, estos anuncios son repetitivos y, a veces, muy desagradables.

## Solución

Con el bloqueador de anuncios en Pi hole con Raspberry Pi 4. Ofrece mejor navegación, mayor
seguridad en la web.

## Componentes Necesarios

- Raspberry Pi 5 (1)
- Tarjeta Micro SD (128 GB) (1)
- Adaptador de corriente (1)
- Cable Ethernet (1)
- Monitor y Teclado (1)
- Multímetro digital (1)
- Laptop/PC (1)
- Router wifi (1)
